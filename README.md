# あみだで発表順

プレゼンの発表順を決めるためのあみだくじアプリです。
1台の画面をプロジェクターなどに映して、みんなで見ながら使うことを想定しています。

## 使い方

1. **人数を決める**：2〜20人まで設定できます。
2. **名前を書く**：何番目の縦線にするかをみんなに聞いて、線の上に名前を入れます。空欄のままなら「3番の線」のように表示されます。
3. **結果を決める**：線の下に結果を入れます。最初は「1番目」「2番目」…になっていて、自由に書き換えられます（例：「トップバッター」「トリ」）。「結果を「1番目〜」に戻す」で初期状態に戻せます。
4. **くじをはじめる**：横線がランダムに引かれ、結果は「？」で伏せられます。
5. **名前を押す**：その人の線を色付きでたどり、行き着いた先の結果が開きます。「のこりを全部ひらく」で残りをまとめて開けます。
6. 画面下の「発表順」に、結果の順に並べた一覧が出ます。

| ボタン | 動き |
|---|---|
| 横線を引き直す | 名前と結果はそのままで、くじだけやり直す |
| 準備にもどる | 名前・結果・人数を編集する画面に戻る |

## 横線の引き方

手書きのあみだくじで無意識にやっている調整を、ルールとして組み込んでいます。

- **本数**：線と線のすき間ごとに3〜4本（8人以上は4〜5本）
- **行って戻るだけの線を出さない**：同じすき間に続けて横線を引く場合は、その間に必ずとなりのすき間の横線を1本挟みます
- **同じ高さに並べない**：となり合うすき間の横線は同じ高さに引きません
- **見た目**：横線の高さに少しゆらぎを付けて、手書きっぽく見せています

シミュレーションで確認した、自分の真下の結果に落ちる確率は次のとおりです。

| 人数 | 端の人 | 理想（完全に公平な場合） |
|---|---|---|
| 6人 | 約15% | 約17% |
| 11人 | 約10% | 約9% |
| 15人 | 9〜10% | 約7% |

11人くらいまでは、ほぼ理想どおりです。


## 技術メモ

- HTML / CSS / JavaScript だけで、ライブラリは使っていません
- あみだの描画は SVG で、線をたどるアニメーションは `requestAnimationFrame` で動かしています
- フォントは Google Fonts の Zen Maru Gothic と Zen Kaku Gothic New です
- ライトモードとダークモードの両方に対応しています（OSの設定に合わせて切り替わります）
- `prefers-reduced-motion` が有効な環境では、アニメーションを省きます

## 注意点

- **同期しない**：名前・結果・人数は、開いているブラウザの `localStorage` にだけ保存されます。ほかの人の画面とは同期しないので、代表者1人が操作する使い方になります。
- **保存されないもの**：横線の配置と開いた結果は保存されません。ページを再読み込みすると準備画面から始まります。
